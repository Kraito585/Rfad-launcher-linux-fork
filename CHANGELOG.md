# Улучшение взаимодействия со Steam

## Основные изменения

- Добавлена кнопка "Добавить в Steam".
- Добавлено меню, заменяющее окно Steam с вариантами запуска.
- Отключена функция копирования MO2 из другой копии игры.
- С UI лаунчера теперь можно взаимодействовать при помощи геймпада.

## Подробнее об обновлении

### Добавлена кнопка "Добавить в Steam"

Найти кнопку можно в DropDown-меню по нажатию кнопки шестерни возле кнопки "Играть".

![Тут должно быть изображение](https://i.ibb.co/5gzy9SsF/image.png)

Для того чтобы игра появилась в Steam, нужно перезапустить клиент Steam.

Лаунчер будет принудительно запущен, если потребуется миграция или он не сможет найти файлы игры.

### Добавлено меню, заменяющее окно Steam с вариантами запуска

Поскольку оригинальный функционал с вариантами запуска в Steam недоступен для сторонних игр, было создано заменяющее окно.

![Тут должно быть изображение](https://i.ibb.co/xtH2GnC2/image.png)

Если вы сохранили вариант запуска и хотите вернуть окно, запустите лаунчер вручную и измените вариант запуска в настройках.

### Отключена функция копирования MO2 из другой копии игры при установке

Функция могла бы быть полезной в некоторых случаях, но она слишком часто приводила к замешательству пользователей.

### С UI лаунчера теперь можно взаимодействовать при помощи геймпада

Со всем UI, включая установку и окна с вариантами запуска, можно взаимодействовать при помощи геймпада.
