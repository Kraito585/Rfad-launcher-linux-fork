## Основные изменения

- AppImage теперь работает исправно.
- AppImage работает на `gtk-3.1`, `webkit2gtk-4.1`.

## Подробнее об обновлении

Wails3 не умеет билдть `AppImage` под свежие `gtk-4.0` и `webkit-6.0`, поэтому версия под `AppImage` будет работать на устаревшем `gtk-3.1` и `webkit2gtk-4.1` остальные версии продолжают работать на свежих библиотеках.

## Minor

- Build теперь происходит через стандартный `build container wails3`.
- Build container был доработан: внедрён fallback официальных зеркал для `zig: https://ziglang.org/download/community-mirrors.txt`.
- Таблица совместимых с OS пакетов была обновлена.
- В мануале по ручной сборке проекта добавлена рекомендуемая версия для `NodeJS`.
