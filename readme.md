# RFAD Launcher Linux Fork

## WebUI был взят из репозитория: [`Amirust`](https://github.com/Amirust/rfad-launcher)

### Backend был полностью переписан и доработан. Все процессы автоматизированы настолько, насколько это возможно.

Крайне рекомендуется установка через лаунчер.
При ручной установке есть риск того, что смена графических модификаций сломается.

Лаунчер самостоятельно устанавливает игру, распаковывает **СВОЙ Proton/Wine** и **СВОЙ Prefix**.

Запуск игры осуществляется через лаунчер в меню пуск. В настройки добавлен новый функционал для улучшения пользовательского опыта на Linux.

## Частые вопросы:

### Что делать, если у меня уже есть сборка с сохранениями и собственными модификациями?

1. Выберите «Установить игру».

2. Согласитесь на портирование директории MO2.

3. Дождитесь окончания установки и наслаждайтесь игрой.

#### ⚠️ Внимание: Перенос в пределах одного накопителя использует жесткие ссылки (hard links) и не расходует дополнительное место на диске, но вам всё равно потребуется свободное пространство для первичной распаковки игры.

#### ⚠️ Внимание: Перенос между разными накопителями расходует дисковое пространство. Во избежание повреждения данных символические ссылки (symlinks) не используются.

### Что делать, если мне нужны дополнительные библиотеки (.dll) для моего мода?

Существуют два пути.

### Первый путь (более простой и надежный):

#### ⚠️ Важно 1: Если вы зайдете в раздел восстановления и вылечите/переустановите Prefix или Proton, Prefix будет сброшен до настроек по умолчанию.

#### ⚠️ Важно 2: В вашей системе должен быть установлен [`Protontricks`](https://protontricks.com/).

1. Нажмите на шестеренку возле кнопки «Играть».
2. Выберите [`Protontricks`](https://protontricks.com/).
3. В открывшемся окне [`Protontricks`](https://protontricks.com/) доустановите нужные вам библиотеки.

### Второй путь (требует знания, какие именно .dll нужно установить в Prefix):

#### ⚠️ Важно 1: Если вы зайдете в раздел восстановления и переустановите Prefix, он будет сброшен до настроек по умолчанию.

#### ⚠️ Важно 2: Может понадобиться добавление .dll в строку `WineDllOverrides` во вкладке настроек.

1. Зайдите в директорию `game_dir/wine/tmp/libs`.
2. Положите туда .dll файлы, которые хотите добавить в Prefix.
3. Нажмите на шестеренку возле кнопки «Играть».
4. Перейдите в раздел «Восстановление» и выберите пункт «Prefix - Вылечить».
5. Дождитесь завершения восстановления и запускайте игру.

## Ручная сборка (Build)

Все пути указаны относительно корня проекта. Все команды необходимо выполнять в корне проекта.

Клонируйте репозиторий:

```
git clone https://github.com/Kraito585/Rfad-launcher-linux-fork.git
```

```
cd Rfad-launcher-linux-fork
```

### 1. Подготовка окружения (Wails v3)

Убедитесь, что у вас установлен `Go` (версии 1.25+), `Node.js 26` (или npm), `Docker` и `Wails` v3 CLI:

```
go install github.com/wailsapp/wails/v3/cmd/wails3@latest
```

### 2. Варианты сборки

Проект использует встроенную систему задач `wails3 task` и `Docker` для кросс-компиляции и упаковки.

#### Вариант А: Сборка пакетов (AppImage, DEB, RPM, ZST)

Для создания готовых к распространению пакетов под разные дистрибутивы Linux потребуется Docker.

1. Создайте базовый Docker-образ (выполняется один раз):

```
DOCKER_BUILDKIT=1 wails3 task setup:docker
```

2. Запустите сборку пакетов:

```
wails3 task linux:package
```

Все готовые пакеты, включая rfadlauncherlinux-x86_64.AppImage, появятся в папке bin/.

#### Вариант Б: Быстрая локальная сборка (Binary)

Если вам нужен только бинарный файл для тестирования в вашей текущей системе (без упаковки в AppImage):

```
go mod tidy
```

```
wails3 build
```

Исполняемый файл будет лежать в директории bin/RFADLauncherLinux.
