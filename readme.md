## Крайне рекомендуется установка через лаунчер.

_При ручной установке есть риск то что смена графических модов сломается_

Launcher самостоятельно устанавливает игру распаковывает **СВОЙ Proton/Wine** и **СВОЙ Prefix**.

Запуск игры осуществляется через лаунчер в корне игры.

В настройках добавлен новый функционал для улучшения пользовательского опыта на Linux.

## **Отвечаю на возможный вопрос:**

### **_Что делать если у меня уже есть сборка с сохранениями и собвствеными модификациями?_**

1. Выберите установить игру.
2. Соглоситесь на портирование дериктории MO2.
3. Ждите окончания установки наслождайтесь.

#### Warn: Перенос в пределах одного накопителя использует hard links не расходует место на диске, но вам всё ровно нужно пространство на первичную распаковку игры.

#### Warn: Перенос между двумя накопителями расходует пространство я не буду использовать sim links и рисковать целостностью данных.

### **_Что делать если мне нужны дополнительные библиотеки/dll для моего мода?_**

Тут существуют два пути.

Первый и более простой и надёжный.

**_Warn: 1_ Если вы зайдёте в востановление и выличите/переустановите Prfix или Proton, prefix будет сборошен до дефолта.**

**_Warn: 2_ ProtonTrics должен быть установлен в системе.**

1. Нажмите на шестерню возле кнопки играть.
2. ProtonTrics.
3. В открывшемся окне ProtonTrics доустонавите нужные вам библиотеки.

Второй способ требует от вас знание какие именно dll нужно установить в Prefix.

**_Warn: 1_ Если вы зайдёте в востановление и переустановите Prfix то он будет сборошен до дефолта.**

**_Warn: 2_ Может понадобится добовлние dll в строку WineDllOverrides во вкладке настройки.**

1. Зайдите в game dir/wine/tmp/libs.
2. Положите туда dll файлы которые хотите добавить в Prefix.
3. Нажмите на шестерню возле кнопки играть.
4. Перейдите в "Востоновление" выберите пункт "Prefix - Вылечить".
5. Дождитесь завершения востоновления и запускайте игру.

# Ручной билд

_Все пути указаны относительно корня проекта. || Все команды надо выполнять в корне проекта._

Скачать репазиторий `git clone https://github.com/Kraito585/Rfad-launcher-linux-fork.git`

Перед билдом нужно зайти на страницу [`Console Google`](https://console.cloud.google.com) и выполнить следующие действия

`APIs & Services --> Libry --> Google Drive API --> enable`

Затем возврощаемся [`Console Google`](https://console.cloud.google.com) и выполняем следующие действия

`IAM & Admin --> Service accounts --> Create service account --> Придумайте свои даные --> Нажмите на свеже созданый сервисный аккаунт --> Kyes --> Add key --> Create New Key --> JSON`

У вас скачается JSON файл переиминуйте его в `credentials.json` и положите его в `embed/credentials.json`

## Варианты билда

Далие у нас есть два варианта билда `binary` и `.AppImage`

### Для binary нужно выполнить команды

- `go mod tidy`

- `wails build`

Файл будел лежать в `build/bin/RFADLauncherLinux`

### Для .AppImage нужен [`Docker`](https://www.docker.com/)

С перва нужно сбилдить Docker образ командой. **_(Эту команду не нужно выполнять при повторном билде.)_**

`docker build --network=host -t rfad-builder .`

Затем сам билд лаунчера

`docker run --rm --network=host -v $(pwd):/src rfad-builder`

Файл будел лежать в `RFAD_Launcher-x86_64.AppImage`
